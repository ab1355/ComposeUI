🎨 ComposeUI - Simple Example

This page demonstrates the basic usage of ComposeUI's composable component system.

1. Emoji Authentication

Try logging in with the emoji pattern: 🔐🌟🎯

2. Dynamic Dashboard

Once logged in, you can add components to the dashboard below:

3. Code Example

Here's how the above works:

// Initialize ComposeUI
const composeUI = new ComposeUI();
const emojiSecurity = new EmojiSecurity();

// Register user
emojiSecurity.registerUser('demo', '🔐🌟🎯', ['*']);

// Authenticate
const result = emojiSecurity.authenticate('demo', '🔐🌟🎯');

// Create dashboard and add components
if (result.success) {
    const dashboard = composeUI.createDashboard('main');
    composeUI.addToDashboard('main', 'stat-widget', {
        emoji: '👥',
        value: '1,234',
        label: 'Users'
    });
    composeUI.mount('main', '#app');
}
